# Concept / Topics page guidelines

See [template.md](template.md) §3. Concept pages explain ideas; they do not require `## Sample script` unless a small runnable helper exists.

Required for Topics modules in the core curriculum:

- `**On this page**` + `[TOC]` when the page is long.
- `## Key terms` before `## References`.
- Optional YAML front matter: `type: concept`, `concepts:` list for knowledge-graph linking.

Link to hands-on modules for pipelines (e.g. LD theory → `08_LDSC`).
